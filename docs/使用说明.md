# 声刻 0.4.0 使用说明

从文件开始：在 Finder 右键音频 →「打开方式」→「声刻」，或拖入应用窗口 / Dock 图标。文件已关联声刻时，双击即可打开。应用位于 `dist/声刻.app`。

## 保存

| 按钮 | 结果 |
| --- | --- |
| 写入并覆盖原文件（⌘S） | 按源文件格式、编码、采样率和声道保存完整编辑结果；PCM 保留原位深和浮点类型 |
| 保存为副本（⇧⌘S） | 选择副本名称和位置，使用源文件编码；原文件不变，当前源文件目标也不变 |
| 删除源文件并保存为 WAV | 在原目录保存 WAV 24-bit，保持采样率和声道；校验通过后把源文件移入废纸篓，当前编辑对象切换到新 WAV |

三个按钮都保存完整音频。若需要独立片段，选中后按住选区内部拖到 Finder 文件夹，松开生成 WAV 48 kHz / 24-bit / 立体声，首尾自动加 15 ms 淡入淡出。此操作不修改源文件，也不清除本次编辑的未保存状态。文件名旁橙点表示当前音频修改尚未保存；覆盖或成功保存副本后橙点消失。

第三按钮遇到同名 WAV 时自动使用「-转换」「-转换-2」等名称，不覆盖已有文件。保存失败不删除源文件；若 WAV 保存成功但移入废纸篓失败，会显示原因并保留两个文件。源文件被其他软件修改后，覆盖和转 WAV 操作会停止，此时可以保存副本。

MP3/AAC 会重新编码，并非无损剪切；VBR 会按原平均码率重新编码。原标签、封面、BWF 信息和文件内标记尚不保留。内部处理精度为 Float32；Float64 源文件保存时仍使用 Float64 文件编码，但不会恢复已降低的处理精度。

## 剪辑和试听

1. 单击波形设置光标；横向拖动超过 3 点建立新选区，轻微手抖不会留下毫秒级误选。已有边界仍可精细拖动。右侧可以输入时间或整数样本帧，回车确认。
2. **空格播放/停止，P 或逗号暂停/继续，X 停止并定位，Esc 停止。** 正常空格试听选区；Shift+空格从选区起点或光标播放到末尾。4 / ⌘L 切换循环。选区很短时，播放结束会提示其长度。
3. ⌘X/C/V 剪切、复制、粘贴；Delete 删除；⌘T 只留下选区；⌘Z 撤销，⇧⌘Z 重做。文字输入框内使用文字编辑命令。
4. 淡入 D、淡出 G 要求先选范围；整段淡化先 ⌘A。归一化、倒放、反相等在无选区时处理整段，注意右侧范围提示。
5. 选中片段后，中上方出现小音量旋钮。指针放在旋钮上，滚轮向上增加、向下降低音量，Shift＋滚轮精调，也可上下拖动旋钮。范围为 −60 至 +24 dB；点击其他地方即完成，整次调整可一次撤销。边界在约 15 ms 内从原音量平滑过渡到新音量；极短选区缩短过渡，不挪动样本。1–2 帧选区因两端都需要保持连续，不应用有效增益。归一化仍可设 −96 至 0 dBFS 并预听 5 秒；它是样本峰值处理，不是 LUFS。
6. R/T 缩小/放大；Q/W 到选区两端；E 恢复上一视图；⌘0 显示全曲。**波形区域直接滚动鼠标滚轮，以指针下的时间点为中心横向缩放**，不需要按 Command；向上放大、向下缩小。Shift＋滚轮、横向滚动或 Option 拖动用于平移；捏合也可缩放。旋钮上的滚轮专门调整音量。振幅倍率只改变显示。
7. M 添加临时标记，⌥← / ⌥→ 跳转。标记仅在本次编辑有效，不保存为工程，也不写入音频文件。
8. 双击顶部标题栏放大到屏幕可用范围，再双击还原；不切换到独立全屏空间。
9. L/R 电平在监听音量之前，显示样本峰值；点击峰值数字复位。监听音量与静音不影响保存。
10. 数字 3 或录音按钮使用系统默认输入；真实录音和外部设备仍待验收。

关闭或换文件时，有未保存音频会提示覆盖、取消或放弃。保存成功后才继续关闭或打开。选区、视窗、标记和撤销记录不跨次保存。

## 使用建议与拖出片段

右上角「！」随时打开建议编辑框，点击「关闭」即保存，输入过程中也自动保存。实际 Markdown 文件在 `~/Library/Application Support/WaveStudio/使用建议.md`；以后版本只更新文件头的版本号，保留全部旧建议。拖入 `.md` 可追加文本，不覆盖原建议。

拖出片段时，从已选中范围内部按住并拖动；靠近两端仍是修改选区边界。单声道导出为左右相同的立体声；双声道保持左右关系，不同采样率转换为 48 kHz。淡入淡出在重采样后执行，15 ms 对应 720 帧；短于约 30 ms 的片段缩短两端淡化，保证不越界。文件名含源名称与选区起止毫秒；同名目标不静默覆盖。

音量调整使用原信号与增益后信号的互补权重交叉过渡，避免人为制造瞬时增益跳变；不会重新归一化整段或强制抹平你想要的音量差异。实际声音仍应按素材试听。

当前一次处理一个单/双声道文件，粘贴要求同采样率/声道。无崩溃恢复；更多限制和测试证据见 [README](../README.md) 与 [验证范围](VERIFICATION.md)。
